# Deloitte Australia – Data Analytics Job Simulation

## Overview
Completed the **Deloitte Australia Data Analytics Job Simulation** through [Forage](https://www.theforage.com/simulations/deloitte-au/data-analytics-s5zy).

This virtual job simulation provided practical exposure to data analysis and forensic technology through tasks based on simulated workplace scenarios.

## Tasks Completed

### Task 1: Data Analysis
- Analysed simulated client telemetry data.
- Explored how machine downtime data can be examined to identify operational issues.
- Practised data visualization and dashboard development using Tableau.
- Learned how visual insights can support business decisions.

### Task 2: Forensic Technology
- Worked on a simulated business scenario involving workplace equality analysis.
- Practised analysing equality scores and classifying results using spreadsheet logic.
- Explored how data analysis can help identify potential fairness concerns and support evidence-based conclusions.

## Skills Practised
- Data Analysis
- Tableau and Data Visualization
- Microsoft Excel and Spreadsheet Formulas
- Data Interpretation
- Analytical Thinking and Problem-Solving
- Business Insights and Decision Support
- Forensic Technology Fundamentals

## Key Learnings
- Translating business questions into analytical tasks.
- Using data visualization to communicate findings clearly.
- Applying spreadsheet logic to classify and interpret data.
- Connecting analytical results to business problems.
- Understanding how data supports operational analysis and fair decision-making.
